# Способ сбора морфофизиологических данных свиней — лендинг

Презентационная страница проекта программы «Студенческий стартап» Фонда содействия инновациям (заявка СтС-514953).
Статичный HTML + CSS, без JavaScript, сборки и зависимостей.

Спецификация: [docs/superpowers/specs/2026-09-14-pig-monitoring-landing-design.md](docs/superpowers/specs/2026-09-14-pig-monitoring-landing-design.md)

## Структура

```
index.html                 страница
css/style.css              стили (токены цвета — в начале файла, блок :root)
assets/fonts/              IBM Plex Sans / IBM Plex Mono, woff2 (SIL OFL 1.1)
assets/img/placeholders/   заглушки изображений (продукт, компоненты)
assets/img/logos/          официальные логотипы партнёров (футер)
tests/                     проверка текстов и контраста
```

## Как заменить изображения

1. Положите файл в `assets/img/` (JPG, PNG или WebP; желательно не менее 1600 px по ширине, пропорции любые — слот 4:3 обрежет лишнее по центру).
2. В `index.html` поменяйте атрибут `src` нужного слота и уточните `alt` (что изображено на снимке).

Вёрстку трогать не нужно. У фото продукта и компонентов есть по два `<img>` (миниатюра + копия в полноэкранном просмотре) — при замене `src` меняйте оба.

Клик по фото открывает его крупнее на весь экран с плавной анимацией (закрывается кликом по фону или крестику). Сделано на чистом CSS (скрытый чекбокс + `:checked`/`:has()`), без JavaScript и без переходов по ссылкам — см. `.lightbox-toggle`/`.lightbox` в `index.html` и `css/style.css`.

| Слот | Текущий `src` | `alt` |
|---|---|---|
| Фото продукта (блок «Описание продукта») | `assets/img/placeholders/product.svg` | «Фото продукта» → описать реальный снимок |
| Компоненты и датчики (блок «Описание продукта») | `assets/img/placeholders/gallery-2.svg` | «Компоненты и датчики» |
| Логотип Фонда (футер) | `assets/img/placeholders/fasie-logo.svg` | «Логотип Фонда содействия инновациям» |
| Логотип федерального проекта «Технологии» (футер) | `assets/img/logos/tech-federal-project.png` | «Логотип федерального проекта «Технологии»» |
| Логотип программы + Минобрнауки России (футер) | `assets/img/logos/university-tech-platform.png` | «Логотип программы «Платформа университетского технологического предпринимательства» и Минобрнауки России» |

Логотипы в футере отображаются высотой 72 px на тёмном фоне — нужны версии с прозрачным фоном (PNG/SVG), светлые или достаточно контрастные на графитовом фоне. Если пропорции логотипа отличаются от указанных, поправьте атрибуты `width`/`height` у `<img>` под реальные пропорции файла. Логотипы идут в ряд (`.footer__logos`, flex-обёртка) — добавить ещё один можно, скопировав строку `<img class="footer__logo" ...>`.

### Фото в шапке (необязательно)

Сейчас шапка — графитовая заливка с инженерной сеткой. Чтобы поставить фото, положите `assets/img/hero.jpg` и раскомментируйте блок «Хук под фото в шапке» в `css/style.css`.

## Тексты

Все тексты взяты из ТЗ дословно. Перед правкой текста обновите эталон в `tests/texts.test.mjs` — иначе тест упадёт, и это задумано: он страхует от случайных изменений формулировок, кавычек и тире.

## Проверка

Нужен Node.js 18+:

```bash
node --test
```

Проверяется: все тексты ТЗ на месте дословно, текст поддержки Фонда совпадает посимвольно, нет лишнего текста, нет JavaScript, все изображения существуют, контраст текста — не ниже WCAG AA.

## Как открыть и выложить

- Локально: откройте `index.html` двойным кликом.
- Любой статический хостинг: загрузите `index.html`, `css/` и `assets/` в корень сайта.
- GitHub Pages: запушьте репозиторий на GitHub → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
