# Лендинг «Способ сбора морфофизиологических данных свиней» — дизайн

Дата: 2026-09-14
Статус: согласовано, реализовано

## 1. Назначение

Презентационный одностраничный сайт научно-технологического проекта (носимое устройство для мониторинга физиологического состояния свиней) программы «Студенческий стартап» Фонда содействия инновациям. Аудитория — эксперты и комиссия Фонда, специалисты АПК, ветеринарии и зоотехнии, потенциальные партнёры. Задача — за 30–60 секунд показать суть метода, преимущества и институциональную поддержку. Не e-commerce: никаких CTA «купить/заказать».

## 2. Жёсткие ограничения

1. Только тексты из раздела 8 — дословно. Никаких выдуманных цифр, характеристик, терминов. Схема принципа работы (раздел 5.2) собрана только из формулировок второго абзаца описания.
2. Текст поддержки Фонда — дословно, без сокращений; логотип — только официальный файл, который предоставляет заказчик.
3. Никакого JavaScript на странице. Анимации — только CSS (hover, fade-in при скролле).
4. Адаптивность: корректное отображение от 320 px до 1920 px.
5. Все изображения на момент сдачи — заглушки; замена на реальные фото не требует изменений структуры вёрстки.

## 3. Стек и файлы

Статичный HTML + CSS, без сборки и зависимостей. Открывается локально двойным кликом и заливается на любой статический хостинг.

```
index.html
css/style.css
assets/fonts/            IBM Plex Sans (400, 500, 600), IBM Plex Mono (400, 500) — woff2, кириллица + латиница; OFL.txt
assets/img/placeholders/ product.svg, gallery-1.svg, gallery-2.svg, gallery-3.svg, fasie-logo.svg
tests/texts.test.mjs     проверка дословности текстов (node:test, без зависимостей)
README.md                как заменить изображения и выложить сайт
```

Шрифты хранятся локально (лицензия SIL OFL это разрешает), чтобы страница не зависела от доступности внешних CDN. Fallback-стек: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` и `ui-monospace, "Cascadia Mono", Consolas, monospace`. Если скачать шрифты не удастся, сайт работает на fallback-стеке без изменений вёрстки.

## 4. Визуальная система (вариант A «Графит + агро-зелёный»)

Референс по палитре — Moocall: тёмная «железная» шапка и футер, светлое тело страницы для длинного текста, один акцентный цвет.

Типографика: IBM Plex Sans — основной текст и заголовки; IBM Plex Mono — служебные подписи (надпись в шапке, метки разделов «01 Описание продукта», номера карточек и шагов). Заголовок в шапке: 600, 44 px на планшете и десктопе; на узких экранах размер привязан к ширине вьюпорта (`min(2.75rem, (100vw − 40px) / 12.5)`: ~22 px при 320 px, ~27 px при 375 px), чтобы слово «морфофизиологических» помещалось в строку без разрыва — автоматические переносы для русского языка поддерживаются браузерами ненадёжно.

Стилистика: тонкие линии 1 px, скругления 4–6 px, без теней и градиентов; акцентная полоса 2 px сверху у карточек преимуществ.

## 5. Структура страницы

Порядок блоков повторяет логику Halter «что это → как работает → что получает пользователь».

### 5.1 Шапка (`<header class="hero">`)
- Фон — `--c-graphite` с инженерной сеткой (два `linear-gradient`, шаг 28 px). Готовый хук под фото: закомментированная строка в CSS (`background-image` с затемнением), фото сейчас не используется.
- Надпись над заголовком (Mono, uppercase, `--c-accent-on-graphite`): «Студенческий стартап · Фонд содействия инновациям» — согласовано с заказчиком.
- `<h1>`: «Способ сбора морфофизиологических данных свиней».
- Под заголовком — акцентная черта 64×2 px.
- Высота по содержимому (не 100vh), чтобы было видно продолжение страницы.

### 5.2 01 — Описание продукта (`<section id="description">`)
- Метка раздела `<h2>`: «01 Описание продукта».
- Сетка 7fr / 5fr: слева текст, справа слот изображения продукта (4:3).
- Первый абзац — вводный (крупнее, `--c-ink`), второй — обычный.
- Под ними — схема принципа работы: 4 шага в одной рамке, между шагами стрелки «→» (на узких экранах «↓»). Разметка — `<ol>`, каждый шаг — номер, `<h3>` и пояснение:
  1. **Регулируемая шлейка** — Акселерометр, датчики ускорения и температуры
  2. **Микропроцессор** — С приёмо-передающим устройством и источником питания
  3. **Радиосвязь** — Передача информации об активности и температуре тела
  4. **Единый центр сбора информации** — Обработка и анализ по заложенному алгоритму

### 5.3 02 — Преимущества (`<section id="advantages">`)
- `<h2>`: «02 Преимущества».
- 4 карточки (`<article>`): номер 01–04 (Mono), `<h3>` заголовок, абзац-пояснение. Иконок нет — сознательное решение ради сдержанности.
- Hover: граница карточки окрашивается в `--c-accent`, сдвиг вверх на 2 px, `transition` 0.2 s.

### 5.4 03 — Галерея (`<section id="gallery">`)
- `<h2>`: «03 Галерея».
- 3 карточки `<figure>`: слот изображения 4:3 + `<figcaption>` с номером и подписью: «Вид прибора», «Компоненты и датчики», «Получаемые данные».

### 5.5 Футер (`<footer>`)
- Фон `--c-graphite`, текст `--c-on-graphite-2`.
- Сетка: слева логотип Фонда (высота 64 px, ширина auto, max 200 px), справа текст поддержки дословно.
- На телефоне — логотип над текстом.

## 6. Слоты изображений

Каждый слот — контейнер `.media` с фиксированным `aspect-ratio: 4 / 3` и `<img>` внутри (`width: 100%; height: 100%; object-fit: cover`). Заглушки — SVG-файлы с пунктирной рамкой и подписью слота. Замена фото: положить файл в `assets/img/` и поменять один атрибут `src` (и `alt`). Любое фото любого размера займёт слот без изменения вёрстки.

| Слот | Файл-заглушка | `alt` |
|---|---|---|
| Фото продукта | `assets/img/placeholders/product.svg` | «Фото продукта» (заменить на описание реального снимка) |
| Галерея 1 | `assets/img/placeholders/gallery-1.svg` | «Вид прибора» |
| Галерея 2 | `assets/img/placeholders/gallery-2.svg` | «Компоненты и датчики» |
| Галерея 3 | `assets/img/placeholders/gallery-3.svg` | «Получаемые данные» |
| Логотип Фонда | `assets/img/placeholders/fasie-logo.svg` | «Логотип Фонда содействия инновациям» |

Все `<img>` получают `width`/`height` (против сдвига макета) и `loading="lazy"` (кроме слота продукта, который близко к первому экрану). Таблица дублируется в README.

## 7. Адаптивность, анимация, доступность

**Брейкпоинты** (mobile-first):
- < 640 px: одна колонка везде; схема вертикальная; футер — логотип над текстом; горизонтальные поля 20 px.
- 640–1023 px: описание — одна колонка (фото под текстом); схема вертикальная; преимущества 2×2; галерея 3 колонки.
- ≥ 1024 px: описание 7fr/5fr; схема горизонтальная в 4 колонки; преимущества 4 колонки; контейнер max-width 1200 px, поля 48 px.

**Fade-in при скролле:** CSS scroll-driven animations (`animation-timeline: view()`), прозрачность 0→1 и сдвиг 12 px→0 на входе блока во вьюпорт. Применяется к содержимому разделов 01–03. Обёрнуто в `@supports (animation-timeline: view())` и `@media (prefers-reduced-motion: no-preference)` — где не поддерживается или отключено, контент виден сразу. Шапка и футер не анимируются.

**Доступность и мета:**
- `<html lang="ru">`, `<title>`: «Способ сбора морфофизиологических данных свиней».
- Иерархия: один `<h1>`, разделы — `<h2>`, карточки и шаги — `<h3>`.
- Контраст текста — не ниже WCAG AA (4.5:1 для обычного текста).
- `meta description`, `og:title`, `og:description`, `og:type=website` (для превью ссылок в мессенджерах). В `description` — первое предложение описания продукта дословно. `og:image` не задаётся до появления реальных фото.
- Интерактивных элементов на странице нет; браузерные стили фокуса не сбрасываются.

## 8. Тексты (канонические, дословно)

**Надпись в шапке:** Студенческий стартап · Фонд содействия инновациям

**Заголовок:** Способ сбора морфофизиологических данных свиней

**Описание продукта, абзац 1:** За основу взята технология трекинга физиологического состояния человека за счёт совокупных данных нескольких датчиков: акселерометр, пульсометр, гироскоп, датчик температуры.

**Описание продукта, абзац 2:** Рабочий процесс изобретения достигается за счёт использования регулируемой шлейки, подходящей под анатомические особенности свиньи и оснащённой акселерометром, датчиками ускорения и температуры, микропроцессором с приёмо-передающим устройством и источником питания. Собранная информация об активности и температуре тела животного посредством радиосвязи передаётся в единый центр сбора информации, в котором по заложенному алгоритму происходит её обработка и анализ. Благодаря способу крепления датчиков и удалённому центру сбора информации, предложенный способ отличается надёжностью работы системы по непрерывному получению фенотипических измерений свиней и возможностью оперативно менять алгоритм анализа информации.

**Преимущества:**
1. Эргономичность — Учтены особенности анатомии и физиологии свиней, что позволяет использовать продукт в течение длительного времени.
2. Неинвазивность — Компоненты закреплены наружно, что исключает потенциальные риски травматизации и стресса для животных.
3. Гибкость — Возможность настройки датчиков и хранения получаемых данных.
4. Инновационность — Ранее данный метод не применялся в свиноводстве — всё ограничивалось ручными взвешиваниями и наблюдениями.

**Галерея:** Вид прибора · Компоненты и датчики · Получаемые данные

**Футер:** Проект реализован при поддержке Фонда содействия инновациям в рамках программы «Студенческий стартап» (заявка СтС-514953) мероприятия «Платформа университетского технологического предпринимательства» федерального проекта «Технологии».

Типографика текстов: кавычки «ёлочки», длинное тире «—», буква «ё» — как в ТЗ. В HTML — литеральные символы UTF-8, не HTML-сущности.
